# Symplex Labs

Symplex Labs is an open workshop where projects are built with others and shared with everyone.

## What lives here

- Projects created with contributors
- Tools released as open source after serving a larger system
- Experiments worth sharing

## Current work

- **[bissi](https://github.com/symplex-labs-org/bissi)**: a local-first AI agent.

## Contributing

Open an issue to start a conversation, or send a pull request. Every project here welcomes contributors.

## Part of Metanoia Labs

Symplex Labs is the open side of **[Metanoia Labs](https://github.com/metanoia-labs-org)**. When a project matures into a product, it may continue under a different name within Metanoia Labs, while its open roots stay here.
